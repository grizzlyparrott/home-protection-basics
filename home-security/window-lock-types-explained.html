Window Lock Types: Security Without Blocking an Exit

Reviewed and updated: September 19, 2026. Window hardware must balance security, child-fall prevention, and emergency escape. Local code, a landlord, and the window manufacturer can control what is appropriate.

A window lock only helps when it fits the window, latches fully, and does not create a new escape or fall hazard. Start by identifying the window style and whether it is an emergency-egress opening before adding hardware.

Common lock approaches

  • Integrated sash or casement locks: factory hardware designed for the specific window.
  • Sliding-window locks or pins: supplemental hardware that must be compatible with the frame and opening method.
  • Window stops: limit opening; often considered for child-fall prevention, not a substitute for a security assessment.
  • Window guards: can help prevent falls, but must be releasable where the window is an emergency exit.

Keep emergency escape usable

Do not add a lock, bar, guard, or pin to a bedroom escape window unless it can be opened quickly from inside as required by the product instructions and applicable code. CPSC advises that guards on windows on the sixth floor and below be openable by adults and older children in case of fire. Screens do not prevent falls.

For a rental, ask the landlord before drilling or altering window hardware. For a bedroom, basement, or recently renovated opening, ask the local building department or fire authority whether it serves required egress before making it harder to open.

Check the whole opening, not just the latch

  • Close and lock the window; verify the latch engages without forcing it.
  • Inspect loose frames, damaged tracks, rot, cracked glazing, and obstructed operation.
  • Keep furniture away from windows where children could climb.
  • Do not depend on a screen to retain a child.
  • Test any emergency-release hardware regularly with the people who may need to use it.

Security is layered

Locks are one layer alongside lighting, maintained landscaping, doors, alarms, and routines. CISA recommends securing doors and windows with locks, keys, alarms, and lights as part of a broader physical-security approach. No lock is a promise that a window cannot be forced.
