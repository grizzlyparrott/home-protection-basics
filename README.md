# Home Protection Basics

Home Protection Basics is a home safety and emergency preparedness education website built with custom HTML, CSS, and JavaScript.

The site focuses on practical home safety topics, security basics, emergency planning, maintenance awareness, and homeowner protection concepts. It is built as a real public content site, not a demo project.

Live site: https://homeprotectionbasics.com/

## What this project demonstrates

This project demonstrates my ability to build and organize a static educational website with clear topic structure, SEO-focused pages, internal linking, and responsive layouts.

Key work includes:

- Custom HTML and CSS pages
- Responsive layouts for desktop and mobile users
- Organized article hubs and category pages
- Internal linking between related topics
- SEO-focused page titles, metadata, and site structure
- Sitemap and index management
- Static website deployment through GitHub
- Practical content organization for a public-facing site
